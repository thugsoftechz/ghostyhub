# Contributing to GhostyHub

GhostyHub is a community-driven project. We believe in merit over money, transparency, and user freedom.

## Governance Philosophy
*   **Merit > Money > Marketing**: Technical excellence wins.
*   **Transparent Roadmap**: No silent changes.
*   **Fork-Friendly**: We respect the four freedoms of software.

## Structure
*   **Core Maintainers**: Responsible for Kernel, AI Engine, and UI.
*   **Module Maintainers**: Responsible for specific subsystems (e.g., VR, Emulation).
*   **Community Council**: Elected members who handle policy and community direction.

## Contribution Workflow

1.  **Find an Issue**: Check our GitHub Issues tracker.
2.  **Fork & Clone**:
    ```bash
    git clone https://github.com/yourusername/ghostyhub.git
    cd ghostyhub
    ```
3.  **Create a Branch**:
    ```bash
    git checkout -b feat/your-feature-name
    ```
4.  **Make Changes**: Follow the "No Placeholders" rule. Code must be real and testable.
5.  **Submit PR**: Open a Pull Request. Describe your changes clearly.
    *   Link related issues.
    *   Provide testing steps.

## Development Standards
*   **Language**: Python 3.10+ for tools, C for kernel patches, C++/Qt for UI.
*   **Style**: PEP8 for Python. Linux Kernel Coding Style for C.
*   **Testing**: All new features must have verification steps.

## Code of Conduct
Be respectful. Focus on code. No corporate politics.

## License
By contributing, you agree that your kernel patches are GPLv2, and tooling/UI contributions are compatible with our dual-license model (GPL/Commercial).
